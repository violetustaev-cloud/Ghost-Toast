# Ghost Toast
Ghost Toast is a tiny turn based game.
This version works on windows but is not optimal for html5.
HTML5 and Windows build is avaible to play on itch.io: https://rybarybka.itch.io/ghost-toast

This game was intended as a prototype and learning experience.
For that reason, any critiques on systems, gameplay, and code optimzation is greatly appreciated.
